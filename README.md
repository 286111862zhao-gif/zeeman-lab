# zeeman-lab
本在线虚拟仿真实验以塞曼效应这一诺贝尔奖级经典实验为核心，突破传统磁光实验对暗室、强磁场与精密标准具的高门槛限制，通过高精度3D建模与交互式光路，让学习者在线调节磁场强度、偏振角度及法布里—珀罗标准具参数，实时观察光谱分裂与干涉图样的动态演化，深入理解原子磁矩空间取向量子化、电子自旋与朗德g因子等关键概念。实验采用“虚拟仿真+实体对照”一体化设计，既可反复试错、安全低成本地完成光路搭建与参数调试，又能迁移至真实仪器，弥合理论抽象与操作复杂之间的鸿沟。其沉浸式、可推广、可复现的互动实景模式，不仅显著提升实验教学覆盖面与学习成效，也为近代物理实验数字化转型提供具有示范影响力的解决方案。
